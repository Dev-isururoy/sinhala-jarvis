# Jarvis — සිංහල local desktop agent

A Windows desktop assistant using local Ollama vision inference and faster-whisper.
No paid API, API key, subscription, or cloud inference is required. Initial software
and model downloads need internet; electricity, hardware and internet are not free.

## Start

1. Install Python 3.12 and [Ollama for Windows](https://ollama.com/download/windows).
2. In PowerShell, open this folder and run `./setup.ps1`.
3. Run `./setup-model.ps1` to download the vision and speech models.
4. Double-click **Start Jarvis.cmd**. Use the connection check button.
5. Type a Sinhala or English request, or click **කතා කරන්න**, speak, and click
   **හඬ අවසන් කරන්න**. Review/correct the transcript, then click **ආරම්භ කරන්න**.
6. The control window minimizes to expose your application. Review each proposed
   action and approve or cancel. The next screen is observed after each action.

Example: `Notepad විවෘත කර ආයුබෝවන් කියා ලියන්න.`

**Stop:** press Esc globally, use Stop in the control window, or move the mouse
to a corner of the primary display (PyAutoGUI fail-safe). Stop prevents subsequent
actions, but does not undo completed actions. A model request already running may
take up to the configured timeout to finish; its result is discarded after Stop.

## What is implemented

- Sinhala/English typed commands and Sinhala microphone transcription with VAD.
- Local screen understanding, normalized mouse coordinates, and visible Windows
  UI Automation control names/IDs to reduce coordinate guessing.
- Click, double/right click, pointer movement, drag, scrolling and key combinations.
- Sinhala Unicode input using clipboard paste; prior clipboard **text** is restored.
  Rich/image clipboard formats are not preserved.
- Launch Notepad, Calculator, Explorer and Paint; open HTTP(S) URLs.
- List directories, read UTF-8 text, write UTF-8 text, and run reviewed PowerShell.
- A bounded observe → propose → approve → execute → observe loop.
- Strict action validation, per-action review, cancellation, and process timeout.
- Screenshots/audio are not written to application logs; the activity log is in
  memory. Screenshots are sent only to the loopback Ollama service. Tasks can still
  open websites or run network commands if the user approves them.

## Model settings and accuracy

Edit `config.json`, rerun `setup-model.ps1` after changing a model, then restart.

| Setting | Default | Tradeoff |
| --- | --- | --- |
| `model` | `qwen3-vl:4b` | 3.3 GB download; CPU inference can be slow |
| `whisper_model` | `small` | Practical CPU baseline; Sinhala accuracy must be evaluated |
| `language` | `si` | Use `en` for English recordings |
| `max_steps` | `20` | Hard action-loop bound |
| `timeout_seconds` | `300` | Local inference HTTP timeout |

For Sinhala recognition experiments, try `medium` or `large-v3` if memory and
latency permit. Larger models are not guaranteed to recognize your speech better.
Use a quiet room, short commands, and review names and numbers in the transcript.
The app downloads the selected speech model on first use if not cached.
There is no measured Sinhala word error rate or task success benchmark for this
installation; it does not claim human-level or 100% accuracy.

## Practical boundaries

This is a supervised desktop agent, not an unrestricted administrator or a VM
sandbox. Actions run with the current Windows user's permissions. It cannot control
UAC secure desktop, the lock screen, or elevated applications from a normal process.
Screen coordinates and UI controls are limited to the primary monitor. Keep the
target there and avoid moving windows while an action is being reviewed.

Review PowerShell and file writes carefully: they can change real files. Cancellation
cannot reverse side effects. Shell execution has a 30-second timeout and attempts
to terminate its process tree; detached processes are not guaranteed to be stopped.
The model prompt tells it to treat webpage/document instructions as untrusted, but
this is not a complete prompt-injection defense; per-action review is mandatory.
No arbitrary Python generated by the model is evaluated by the action dispatcher.

Responses/instructions appear as Sinhala text. Sinhala speech output/TTS, wake-word
listening, MCP server hosting, and unattended operation are not included.

## Troubleshooting

- **Cannot connect:** launch Ollama; rerun `setup-model.ps1`, then connection check.
- **Model missing:** `ollama pull qwen3-vl:4b` (requires Ollama 0.12.7 or newer).
- **Slow inference:** try `qwen3-vl:2b` at the cost of possible accuracy loss.
- **No microphone:** enable Windows microphone access and select a default recording
  device in Windows Sound settings. The recorder uses that device at 16 kHz.
- **Wrong app receives input:** cancel, bring the intended app to the primary display,
  and restart. The agent restores/checks the observed foreground window before input.
- **No Sinhala glyphs:** install/enable the Windows Sinhala language fonts.
- **Focus denied:** restart the task; Windows can prevent foreground activation.

Run tests: `.venv/Scripts/python.exe -m unittest discover -s tests -v`.
